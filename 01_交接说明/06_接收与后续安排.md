# 接收与后续安排

## 1. 接收时确认这四件事

- [ ] 能打开本指南，并了解当前模拟器与 UniDB 是两个独立模块。
- [ ] 能登录服务器，读取当前代码、数据清单和选定权重，确认实际可用设备。
- [ ] 按第四章运行模拟器示例，能区分仅模糊结果、完整退化图和像素位移。
- [ ] 完成现有 UniDB 权重加载与恢复示例，了解演示结果与正式评价的口径差异。

资料整理完成不代表接收人已经成功登录或独立运行。接收人：________　日期：________　待补事项：________。

## 2. 新方法开始前需要明确什么

接手方提供实际使用的一致性方法论文和代码，记录具体提交。随后按照[方法与接口说明](03_当前方法与代码.md)确认：时间方向、固定随机源、网络输入输出、目标函数、采样方法，以及需要的一阶或高阶导数。

新实验还需确定负责人、设备、运行目录、评价口径和预算。原训练程序绑定旧目录、截止时间和源代码身份；继续训练应适配新副本，不能只改日期或直接重启旧控制器。

## 3. 论文如何继续

已有草稿中的方法、实验和结论尚未完成。先确定最终实际实现的方法，再按相同实验口径整理表格与图。论文分工、署名和贡献声明由相关人员确认；入口见[论文与素材](05_论文与素材.md)。
