## 先核对文件，再运行示例

在整个交接目录的根目录执行：

```bash
python3 "02_代码与运行/核对文件.py"
python3 "02_代码与运行/运行示例.py" --help
```

实际运行请按[服务器环境与运行](../01_交接说明/04_服务器环境与运行.md)配置解释器。示例默认从服务器的 `/data2/yanglin` 读取原模块与资产；不要把 `--project-root` 指向这里的中文阅读目录。

训练代码用于理解和后续适配，旧控制器不作为新训练入口。所有新输出写到新目录。

「资料维护」保存页面生成器和文件映射，仅在维护交接包时使用。原始运行记录与历史代码保持在归档中。
