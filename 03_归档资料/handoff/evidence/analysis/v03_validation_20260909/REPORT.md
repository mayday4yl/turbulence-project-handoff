# v0.3 四卡验证与后续研究方案

2026年9月9日凌晨完成计算。对象是单帧、已知原始强度G、现有P2S合成协议下的受控小规模验证；本报告接续9月8日的独立审计。

**结论：当前v0.3未通过门1，停止扩跑两步模型；保留原冻结C0作为基线。** 实际几何校正确实有小幅用途，但“必须沿实际校正状态训练”没有表现出超越简单解耦状态训练的优势。新模型相对旧C0的总体PSNR提升不确定，SSIM反而下降。现在不适合把这版包装成CCF-A主线，也不建议直接用它替换原模型。

**原始假设 → 尝试 → 结果 → 原因 → 当前决定：** 标量弱化状态与真实校正状态错配 → 四种状态来源、两组固定随机顺序、全clean分支微调 → actual胜过scalar，却没有胜过decoupled → “只降低一个强度”不够，但更广的解耦训练已经解释了主要收益，实际轨迹的独立必要性未获支持 → 停止渐进扩跑，先解决微调基线回退和动作质量问题。

## 3. 这次实际比较了什么

- 512个训练原图、128个验证原图、另128个保留测试原图；全局source ID和clean哈希互斥，排除旧诊断129个source ID。每图两组新xi。训练2048个退化实例，验证768个；统计样本量是128原图。
- 四臂为：同xi标量弱化scalar；独立改变tilt或blur的decoupled；图像增量RMS与实际动作匹配的平滑随机扰动generic；冻结v0.1估计器产生的actual校正。
- 网络为相同的22,533,571参数clean分支，输入[当前状态、原Y、冻结C0]，原G与alpha独立条件化。新增输入通道和alpha投影零初始化；初始clean输出与原模型误差为0。
- 每臂每seed 5000次更新，batch32、128裁剪；模拟和校正在完整256图上完成。两seed共有40,000次有效更新，沿用同一预训练权重，独立的是采样/crop/alpha顺序。每个seed内四臂的完整随机序列哈希相同。
- 所有模型使用同一MSE、AdamW配置及BF16精度；现成融合优化器与普通AdamW的10步数值差为0。没有按验证分数选择checkpoint。
- 保留测试集只生成缓存和检查完整性，未读取其恢复评分。模型里的已知G、共同冻结teacher开销、128裁剪微调限制都属于结论边界；不能直接当作真实场景盲恢复成绩。

## 4. 可以解释到哪一步

**已得到支持的解释：标量弱化训练无法覆盖这个部署输入。** actual对scalar约+1.88/+1.86 dB，但decoupled取得相当或更好的PSNR，因此不能把这全部算成“实际轨迹”的贡献。scalar在Y输入上明显好于在T(Y)上，进一步显示本配置中状态来源与推理输入的匹配很重要。

**没有证据表明数值求逆失效是本轮瓶颈。** 缓存中所有校正的求逆残差、越界率和Jacobian检查均通过，没有折叠或fallback；原图拆分、有限值、配对指标和固定C0一致性也全部通过。generic匹配增量RMS的量化相对误差均值约0.004%、最大0.150%，不能把差异归咎于明显不等强度。

**仍未隔离的原因：微调配方和动作质量。** 原始trainer的clean目标本来就是MSE，不能说SSIM下降是“从SSIM损失改成MSE”造成的。128裁剪与256评估的上下文差别、有限数据微调、额外输入和辅助退化目标改变，尚未做因子化控制；也未证明换一个更准的几何估计器就会解决问题。这些是下一轮要区分的假设，不是已证实原因。

当前T(Y)和C0都由Y确定，能够提供计算上的归纳偏置，却不会凭空增加观测信息。前端更接近GT与actual相对generic(Y)的原图增益只有约0.20/0.17的描述性相关；不能凭输入PSNR选择“值得处理”的样本，也不能将这个后见相关性当因果证明。

**门0的范围更窄。** 32个新xi的固定算子探针中，拟合后仍剩约87.1%的相对变化MSE；但只检验固定xi的标量曲线。像素中心identity和整数平移对照为0；另做的分数平移对照，即使连续变换族闭合也留下0.14%-9.44%的示例相对残差。因此门0不能证明全部物理算子族不闭合，也不能把插值、估计误差和空间变模糊分别定量归因。

## 6. 后续方案：建立可靠基线，检验几何信息价值

建议保留“物理校正帮助单帧恢复”的研究问题，暂时撤下“实际轨迹训练已经必要”“渐进步骤已有收益”这两个主张。下一版以**保留原观测和C0的单次残差恢复**为工程底座，先回答动作值不值得学，再决定是否恢复渐进结构。下面是尚未执行的新协议草案，不是本轮成功结果。

**A. 先修复基线回退，参考0.5-1卡时。** 使用C0加零初始化残差输出，使开始训练时严格等于C0；比较不校正与解耦训练两个基础配置，固定两seed。使用完整256上下文，小batch先测速；如果超出额度就缩减这轮问题，不偷偷缩短后再作同等结论。首先要求总体PSNR与SSIM至少不低于C0，并报告分G区间。零初始化残差与完整上下文都是诊断手段，不申报新颖性；若仍回退，应先解决微调稳定性。

**B. 再区分“当前动作收益小”与“估计不够准”，参考1.5-2.5卡时。** 在A通过后，固定同一结构、步数、输入旁路与alpha，比较无动作、当前估计动作、模拟器真实几何动作、打乱方向但匹配强度的动作。每臂都训练对应实际输入，避免拿不适配的旧复原器评估oracle。真实几何提供不可部署的oracle参照，但空间变模糊与重采样仍在，它不是最终复原质量的数学上界。建议预先要求它对无动作至少+0.20 dB、原图区间为正且SSIM不退。若连这个有额外几何信息的参照都没有足够收益，就停止扩展当前几何渐进路线；不外推为所有几何方法无效。

**C. oracle参照有收益后，才研究可部署动作。** 首先做直接二维反向场监督和最终clean损失的标准基线，保留Y与C0，所有像素校正直接采样原Y，避免重渲染clean丢失观测残差。真正待验证的研究问题是：面向最终恢复误差的动作校准，是否比直接flow监督和解耦覆盖更能跨未见强度、估计误差和模拟域泛化。它必须在同调用预算下先赢；否则它仍只是普通几何模块。此阶段先进行针对性的文献复核和小测试，不先开大训练。

以上成本以本次0.09秒/更新、四卡缓存常驻为参考，只是新实验预算估计；完整256训练、几何头和新模拟器都要重新测速。下一轮需在查看保留测试分数前冻结方案；若把当前未使用的128原图用于新筛选，最终论文还必须另设独立测试。A、B合计可先设**3.5卡时上限**，没有通过就停止，而不是不断搜索超参。

CCF-A潜力目前应标为**未建立**。最有依据的继续方式是这个逐级排除路线，而不是宣称已有一套确定能发的复杂方法。如果A、B能通过，才值得投入实现和更大规模研究；如果不能通过，保留原模型和这次负结果，将研究问题重新立项。

| [ET-Turb，CVPR2026](https://arxiv.org/html/2603.01398v2) | 连续曝光与更丰富退化覆盖已有；更多状态不自动等于创新。 |

黎曼方向暂不加入：[2026退化流形预印本](https://arxiv.org/html/2606.06278v1)已有相关组合。对当前一维alpha，正定度量主要改变路径参数化，不能单独提供新的动作方向。本轮缺少的是可验证的增量收益，尚没有引入该模块的实验依据。

本次补查新增了更直接的D²Turb近邻。其作者仓库现有推理结构，但数据和权重链接仍是预留，不能宣称已经取得完整复现包。完整补查、读取范围和访问限制见LITERATURE_UPDATE.md；原paper-search脚本因requests缺失未完成，后续采用原论文与作者仓库直接核验，没有伪报联合索引召回量。

## 8. 成本、安全与可追溯交付

**累计1.7452 NPU卡时，峰值并发4。** 折算四卡同时占用约26.2分钟，实际分准备、测速、两轮训练、让行恢复和评估执行。这个数字包含失败尝试与重做开销；没有用满8.5卡时参考预算，也未使用11:00后的尾部延长例外。

本任务进程显存峰值为**13,664 MB**。395个占卡期间的卡级利用率样本中，中位87%；排除外部同时占用的392个样本后均值75.72%，含加载、保存和评估，不是持续100%。卡级总显存一度达到27,541 MB，其中包含外部任务重叠，不能算作本任务独占用量。

- 外来任务进入1-3卡时，守护器只停止本次创建的四个进程组，让出资源；从4500步检查点续跑。没有终止外部PID，没有重置设备。
- 评估前提前释放融合优化器导致参数内存生存期风险，出现一次NPU评估错误。保留优化器并用独立加载权重比较后，输出最大差为0，八个模型均完成5000步和完整评估。运行错误不计作方法失败。
- CPU打包对NPU优化器checkpoint的反序列化曾触发设备初始化尝试，空可见设备阻止了该操作；随后改用进度日志与字节哈希，未为打包分配卡。
- 收尾核验没有本任务训练worker残留。原model.py、simulator.py、v0.1权重SHA均未变化；旧数据按只读方式使用。约14.72GB新文件保留在/data2/yanglin/v03_validation_20260909。
