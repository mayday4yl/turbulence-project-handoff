# turbulence IR 项目约定

## 版本名称与任务索引

在本项目处理实验、报告、代码或数据前，先阅读 [EXPERIMENT_INDEX.md](EXPERIMENT_INDEX.md)。用户于 2026-09-21 明确规定：

- V0.1 → **v1**
- V0.2 → **v1.5**
- V0.3（老师的递归方案）→ **v2**
- V0.3-half → **v2.5**
- V0.31 / V0.3.1 → **v3**

后续用户可见表述使用新名；引用旧文件时可附原名。旧代码目录、数据集 ID、远端路径、checkpoint、冻结配置及历史报告保留原名，不能为了命名统一做全局替换。

注意：`v03_overfit100_g4321_n4/` 是 **v3 的数据构建项目**；`analysis/v03_validation_20260909/` 是另一个曾使用 v0.3 名称的**几何校正支线**，不得混入老师递归版 v2。具体对应关系见索引。

任务标题只表示主要内容，不能覆盖其历史范围或作为运行状态证据。若旧记忆与用户的新命名冲突，以本表为准；实验事实仍查实际配置、日志和验收记录。

对话默认保留在 Codex 原 `turbulence IR` 项目下显示，使用标题前缀区分版本和用途。此前的三个独立侧栏分区已撤销，不再把这些对话移出原项目。索引中的分类只作内容分类。

本轮命名同步只涉及管理信息，不代表启动、恢复、终止或重跑任何实验。继续其他已授权工作时，仍遵守该任务原有范围。
