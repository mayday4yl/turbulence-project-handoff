**先看当前方法，再按步骤运行。历史版本全部集中在「03_归档资料」。**

下载或解压后，双击根目录的 **[开始阅读.html](开始阅读.html)**。它把当前状态、模拟器图解、方法和运行步骤放在同一个页面，无需联网。

在 GitHub 上直接阅读时，从 **[01｜项目现状](01_交接说明/01_项目现状.md)** 开始。

当前可接手的是**物理模拟器**和**最新 UniDB 恢复基线**。两者尚未组合成会议提出的新一致性方法；最新恢复结果仍未超过输入图的 PSNR 基线。详细状态见第一章。

代码和小规模运行示例已整理；数据、模型权重及完整环境按[服务器指南](01_交接说明/04_服务器环境与运行.md)从现有服务器取得。源码文件名和服务器路径保留原名，方便查找与复现。
