# 新补充的历史决策原件

这五份文件是原项目已有的授权或选型/方案文件，按原字节复制；[清单](MANIFEST.json)记录原路径、字节数及SHA256。它们支持[决策与失败补充](../DECISIONS_FAILURES_AND_OPEN_ISSUES_ZH.md)，不代表现在重新授权执行。

- `RUN_PLAN_PROPOSED_ZH.md`：当时的未执行准备方案，实际训练以最终报告为准。

原文中的绝对路径和相对链接保留历史形式，部分指向本仓库未收录内容；不得据此直接运行旧命令。原始交接包`handoff/`及源码快照没有被重写。
