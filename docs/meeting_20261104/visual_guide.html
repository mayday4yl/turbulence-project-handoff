02 · 模拟器原理

模拟器：从两块随机源到一张湍流图

本说明针对V5实际使用的Smooth＋pixel-center warp＋legacy full IFFT路径。旧v1/V4与V5不能混用。公式来自项目源码；P2S论文解释基础思想，本项目的Smooth、时间接口与历史兼容选择不是原论文的全部原样实现。

1. 它做什么

用 Yg = F(C, ξ, g) 表示退化：给定清晰RGB图C、固定随机实现ξ及强度g，先形成空间变化模糊，再按位移场采样，得到 Yg。这个F不预测clean，不负责反向扩散，也没有optimizer。

图中的数学符号与代码名称对应如下；公式使用上下标，代码标识与文件名保持原字符，方便查找和复制。

图中符号含义代码对应
ξzZernike支路的原始随机源Realization.epsilon_zernike
ξtilt位移支路的原始随机源Realization.epsilon_tilt
ug强度g下的像素位移effective_state.displacement
Bgphys(C)Smooth混合前的物理模糊图render_prepared()内的physical_blur
Yg完整退化图RenderResult.output
g5/6两条随机支路使用的幅度因子self._strength_tensor(g, b).pow(5 / 6)

历史递归方法附录图中的 Nθ 是恢复网络，Zi、ti 是第i次输入状态与时间；Zi+1 是预测后重渲染得到的下一状态。

两类随机源共同描述一次湍流实现：

对象实际形状含义
C[B,3,256,256]FP32 RGB图；训练中的预测clean也能输入
epsilon_zernike[B,36,512,512]36通道独立标准高斯原始随机源，不是最终Zernike系数场
epsilon_tilt[B,512,512,2]两通道独立实高斯原始随机源；末轴是x/y分量，不是复数实部/虚部
g标量或[B]，范围[0,4]退化强度；这里不是扩散的100步时间索引
Zernike场[B,36,256,256]经过相关性与频域滤波后的相位系数
displacement[B,256,256,2]以像素为单位的位移场
RenderResult.flow[B,256,256,2]归一化grid_sample采样坐标，不是像素位移

sample_realization()在CPU固定随机种子生成两块raw，再转设备。跨ARM/x86同seed未必逐位相同，复现正式数据还需原seed/shape/raw SHA及canonical buffers，不能只记一个seed。

2. 模糊支路：raw → Zernike → PSF权重

effective_state()先使用幅度a(g)=g^(5/6)。记R为固定Zernike通道相关矩阵、S为固定空间谱滤波器：

mixed = R × [g^(5/6) · epsilon_zernike]
z_g   = real(IFFT2(S · FFT2(mixed)))，再裁到256×256
w_g(p) = P2S(z_g(p)) ∈ R^100

其中36→100的P2S小网络被冻结，把每个位置的相位表示变成100个空间PSF基的系数。它不是137M参数的UniDB，也不是待训练的恢复网络。

令μ为33×33平均核、b_k为100个33×33基核，物理模糊可写为：

Bphys_g(C)(p) = (μ * C)(p) + Σ[k=1..100] w_g,k(p) · (b_k * C)(p)

prepare_image(C)预先算出平均核与100基核卷积；空间变化体现在每个像素的w不同。卷积先做16像素reflect padding，同一个像素的权重共享给RGB三个通道。P2S基展开没有额外softmax/强制非负或重新归一化，浮点结果可能轻微越过[0,1]。

V5新增Smooth：

α = g/4
Bg(C) = (1-α) · C + α · Bphys_g(C)

这是warp之前的identity/物理模糊混合，等价于h̃g=(1-g/4)δ+(g/4)hg。注意hg本身也随g改变，不能把整条路径理解成固定Y4与C的线性混合。

3. 位移支路：raw → 空间位移 → 采样网格

V5默认tilt_fft="legacy_full"：同一个完整复频域滤波器H分别作用于两块实随机源，沿两个空间轴做完整复IFFT，最后取实部。

u_g = tilt_constant · real(IFFT2(H · g^(5/6) · epsilon_tilt))
grid_g(p) = 2 · (p + u_g(p) + 0.5) / 256 - 1
Y_g = grid_sample(Bg(C), grid_g,
                  mode="bilinear", padding_mode="border", align_corners=False)

pixel_position最后一维是[x,y]。+0.5把像素中心映射到align_corners=False的坐标约定。这里是逆向采样：输出位置p从输入位置p+u取值，不应把箭头画成前向散射。边界外取border；先blur后warp，不可随意互换。

旧v4_irfft分支只是诊断对照，正式V5不使用它。当前legacy路径的非平稳协方差仍是已登记局限；“与历史API等价”不等于物理统计完全正确。

4. 时间如何控制物理路径

V5恢复时间t=1-g/4，所以恢复方向是：

t00.250.50.751
g43210
含义强退化较强中等较弱clean端点

固定C和同一ξ，改变g才是在追踪同一条物理轨迹；每步重新抽ξ会同时改变随机实现。V5训练抽三个严格内部时间并排序，推理默认整数强度。最终g=0是物理端点，不是第五次网络调用。

g=0的前向：g^(5/6)=0使位移为0，Smooth使blur回到C，pixel-center grid使warp为identity。已有端点与图像Jacobian检查支持这一配置。这不保证近零g处任意图像误差都低于固定阈值，也不保证关于g的导数可用；g^(5/6)在0处的导数问题需要新方案单独处理。

5. 可微不等于无条件验收通过

物理资产参数被requires_grad_(False)冻结，但输入C和ξ仍能经卷积、P2S、FFT和grid_sample反传。V5 B通过预测clean/ξ生成下一状态，保留Full-BPTT；不能在这条训练路径包no_grad()或detach()。

已知限制：原Gate的近零边缘绝对误差、部分局部/全图有限差分没有全部通过；后来是在保留这些记录的前提下研究接收。ReLU与双线性插值是分段可微，差分步长跨折点或过小受FP32舍入影响。新增接手示例只检查一个合成点的有限一阶梯度，不能覆盖原FAIL。

依据：原Gate；研究接收决定。若某原件不在便携包，按代码导航的原位置读取。

6. 最小调用

先配置路径与环境，见NPU指南。代码核心是：

from simulator_v5 import build_simulator
sim = build_simulator(device="cpu")  # 原256/512与canonical物理参数
raw = sim.sample_realization(1, seed_zernike=843001, seed_tilt=843002)
result = sim.render(clean_rgb, raw, 2.0)
degraded = result.output
blur_only = result.blur_only

用build_simulator而非仅实例化V5Simulator，前者会绑定原生成侧的canonical buffer。需要同时保留：P2S_model.pt、dictionary.pt、I0_I2.pt、CANONICAL_CPU_REFERENCE.json/.npz，以及对应源码。不同物理参数/分辨率不能强行复用这份canonical参考。

可直接执行的独立示例生成合成RGB图的g=0/.5/1/2/3/4、g4 blur-only与像素位移，并可检查g2处C/raw-ξ梯度。展示PNG会clip，计算和NPY不clip；这些图只讲机制，不是新增恢复实验。

05 · 当前方法与下一步接口

当前方法与下一步接入

1. 当前交接的是两个已有模块

可复用的V5模拟器负责退化生成：清晰图C、原始随机源ξ与强度g输入F，输出一条物理退化路径。最新UniDB D0负责恢复：退化图Y作为条件，通过原生100步reverse SDE得到恢复图。两个模块都有独立运行入口，当前尚未连成会议提出的新consistency方法。

V5的物理恢复时间t=1−g/4，与UniDB内部τ=1…100不是同一变量。接手时先分别跑通二者，再根据接手方真实consistency代码定义接口。

历史只需先记住一条结论：V5 Concertormer B在匹配Val1000上比独立D0高约0.293dB，但第四步仍弱于自身第一步；这说明可以复用物理模块，尚不能声称多步恢复已经稳定有效。D0/A/B目标与完整展开公式放在历史方法附录。

2. 当前UniDB：当前有条件扩散，但没有外层物理递归

官方DIV2K SR gamma_1e7.pth初始化，固定commit见论文/官方源。项目core.py的NativeObjective.forward执行：

  1. 给clean和degraded生成随机τ及桥状态。
  2. 条件UNet以当前状态、Y、τ预测noise；通过原生公式转score。
  3. 比较预测反向一步均值与使用GT计算的目标均值，MatchingLoss(loss_type='l1')。

这是一步均值L1匹配，不是直接回归最终100步图的clean MAE。推理set_mu(Y)后从Y调用100步reverse_sde。没有把Y先改成随机高斯、没有VQ往返，也没有F参与100步采样。 UNet内部先计算xt-cond，再与cond拼接；输入条件细节见官方源码，不把它描述成单纯3通道无条件UNet。

原线保持原生目标从U45411续至U67180；另一线从官方U0使用ε_opt MSE、warmup/不同LR/clip等训练至U40848。多项因素同时改变，不是单因素loss消融。最终质量和详细诊断见旧主报告第7节。

3. 接手方要接的接口

会议（12:36–14:54、18:38–20:00）提出：把既有consistency bridge的线性插值换成由物理模型控制的路径，并适配NPU。会中“CGDB”等称呼需与接手方实际稿件和代码确认，公开同名检索不能证明就是团队版本。

附录：V5递归方法与历史比较

1. 三种“时间/步数”不是一回事

路线时间变量一次恢复做什么物理F是否在恢复闭环里
V5 Concertormer恢复时间t∈[0,1]，g=4(1−t)4次网络预测；前3次后重退化生成下一状态是
V6 DiffUIR-L内部扩散时间＋外层物理时间内部S3与外层A/B分别计数D0无；历史物理A/B有

会议中的consistency方案待接手方确认拟用物理路径替代原线性插值，并改训练/采样待实现

D0表示该实验内的直接恢复基线，不是所有版本共用一个checkpoint。V5的observation consistency、UniDB的MatchingLoss和consistency model训练目标也不是同一种loss。

2. V5：先直接恢复，再单步训练，再真实递归对齐

D0：clean-only

C_hat = Dθ(Y4)
L_D0 = MAE(C_hat, C)

正式D0无时间条件、raw-ξ头、Simulator或refinement。官方Concertormer GoPro主体全参数微调，完成10k更新。

A：预生成物理中间态的单步学习

(C_hat, ξ_hat) = Nθ(Y_g, t),  g=4(1−t)
L_A = 0.9 MAE(C_hat,C) + 0.1 MAE(F(C_hat,ξ_hat,g), Y_g)

A训练输入是预生成当前强度观测，回投匹配当前Yg；不是在线四步Full-BPTT。完成6k更新，但best通过原始G4 Val1000真实四步推理选择，不能把更容易的Val-A数值放入G4主表。

B：自身预测形成下一状态

Z0 = Y4
for i = 0..3:
    (C_hat_i, ξ_hat_i) = Nθ(Zi, ti)
    Li = 0.9 MAE(C_hat_i,C) + 0.1 MAE(F(C_hat_i,ξ_hat_i,4),Y4)
    if i < 3: Zi+1 = F(C_hat_i,ξ_hat_i,g_i+1)
L_B = mean(L0,L1,L2,L3)
return C_hat_3

所有阶段的B回投都对最初Y4；下一状态用预测clean与预测raw，GT只作监督。保留整链梯度，不detach；正式训练/选模refinement OFF。B完成4k。D0/A/B在同一原Val1000的best PSNR为21.443506 / 20.156652 / 21.736105dB。B−D0=0.292599dB，但B第四步−第一步=−0.105346dB。证据。

3. UniDB：当前有条件扩散，但没有外层物理递归

官方DIV2K SR gamma_1e7.pth初始化，固定commit见论文/官方源。项目core.py的NativeObjective.forward执行：

  1. 给clean和degraded生成随机τ及桥状态。
  2. 条件UNet以当前状态、Y、τ预测noise；通过原生公式转score。
  3. 比较预测反向一步均值与使用GT计算的目标均值，MatchingLoss(loss_type='l1')。

这是一步均值L1匹配，不是直接回归最终100步图的clean MAE。推理set_mu(Y)后从Y调用100步reverse_sde。没有把Y先改成随机高斯、没有VQ往返，也没有F参与100步采样。 UNet内部先计算xt-cond，再与cond拼接；输入条件细节见官方源码，不把它描述成单纯3通道无条件UNet。

原线保持原生目标从U45411续至U67180；另一线从官方U0使用ε_opt MSE、warmup/不同LR/clip等训练至U40848。多项因素同时改变，不是单因素loss消融。最终质量和详细诊断见旧主报告第7节。
