# 固定 GT-forward 噪声与激活诊断

四个 EMA 节点 U0/U500/U10000/Final 在相同 GT-forward 状态上比较网络噪声预测。共 16 个来源/强度组合（8 个独立来源：4 train、4 val；G1/G4），各首个实现、t10/50/90，192 次前向。不能把 16 组合、48 个状态或 192 条记录当作对应数量的独立来源。

真实 ε 是实际 CPU 采样标准 Gaussian，用于构造 x=f_mean(clean,t;mu=y)+f_sigma(t)ε。它与原生 MatchingLoss 的精确目标不同：原目标是离散 GT posterior 的均值 μstar，而预测采用 Euler 均值 A*x+B*y−C*noise。这里按 ε_opt=(A*x+B*y−μstar)/C 反解与原生 L1 等价的噪声目标；分别报告真实 ε 和 ε_opt 的相关性、余弦和 MAE。
