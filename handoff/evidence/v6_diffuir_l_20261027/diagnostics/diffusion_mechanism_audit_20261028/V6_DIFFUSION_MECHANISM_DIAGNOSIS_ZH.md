# V6 DiffUIR 实际网络行为与扩散机制诊断

日期：2026-10-28。所有新测试均在独立 CPU 副本上完成；正式五卡 B 不曾暂停、改配置或恢复重启。本轮没有 optimizer update，没有 Test1000 评价。理论与源码详解见同目录 `DIFFUIR_THEORY_AND_CODE_AUDIT_ZH.md`。

## 1. 先给分层判断

| 层面 | 本次能够支持的结论 | 不能替代的结论 |
|---|---|---|
| 结构 | V6 保留官方选定的 Residual Conditional Diffusion 训练及带SDT的简化逆采样；D0新增目标明确是Lres+真实S3 Clean | “完整保留官方路径”不等于未经近似的标准DDPM/DDIM或严格后验采样 |
| 行为 | 在所测数据上，状态、扩散时间和初始Gaussian对输出均有可测响应；不能把网络视为严格与x/τ/噪声无关的condition-only函数 | 不排除模型的大部分恢复能力来自强Condition，或其功能接近带状态/时间调制的迭代恢复器 |
| 性能 | 同checkpoint、相同初始噪声的合法完整NFE测试中，D0三步相对一步有PSNR收益；不是所有指标/NFE都由三步领先 | 不是比独立训练普通恢复器更强的因果证明，也不是生成能力证明 |
| 方法 | 原生项仍有梯度，新增Clean项也真实反传；有保留当前冻结实验以形成对照的工程与局部性能依据 | 没有单独识别新增LC的因果收益、原生分布学习是否变弱或1:1是否最优 |
| 工程 | 在本次覆盖的活跃路径中，未发现V6擅改噪声/残差目标、截断S3或意外detach的错误 | 官方已有终端分布差异及Reverse近似不能被称为“数学上全无疑点” |

因此，最准确的结论是：**没有观察到“扩散被完全训没、状态与时间已被彻底忽略”；观察到强Condition主导、但状态/时间仍被利用，三步有局部PSNR价值。生成分布/真实后验能力仍未证明。** 不能再把这一结论简化成“所以完全没问题”。

## 4. Forward终端和Inference初始化：确有官方已有差异

实际 `a999=0.9936471581,b999=0.9999797940,d999=0.9004999995`。归一化域：

\[
q(x_{999}|c,y)\approx\mathcal N(0.006352842c+0.093147159y,0.99995965I),
\quad p_{init}(x|y)=\mathcal N(0.0995000005y,0.01I).
\]

原生线性VP噪声表没有乘sum_scale；后者控制当前推理初始std=0.1。有限a产生的均值差为`−(1−a)r`。固定样本128次32²纯q重放，经验方差约1.00006048/0.01000101，q公式最大误差4.77e−7；没有把网络分辨率降为32²。

这三套模型均有相同关系。论文Algorithm2使用bT，而公开执行代码使用sqrt(sum_scale)；V6沿用代码。**登记为官方定义/配置之间的分布差异，理论严格一致性未建立；不未经证据标成V6 Bug，也不自改噪声继续实验。** 若未来要“修正”它，会形成方法/采样协议研究变更；该变更及依赖它的新训练应等待明确研究决定。本轮只读审计可继续，现有已授权B保持冻结协议。

归一化Jacobian增益估计：令输出raw residual为f，输入u为x或Concat y，用两个单位方差Rademacher探针估计`||J_u||F/sqrt(Nout)`，再乘`RMS(u)/RMS(f)`；这是无量纲局部增益，两个探针只提供轻量估计。有限差分是对输入RMS归一化的同一白噪声方向，计算`RMS(f(u+hδ)−f(u−hδ))/(2h)`；h为归一化RGB单位，实际RGB扰动是h/2。两档h与Jacobian原始增益可在SENSITIVITY.csv逐行交叉检查。 实际交叉复算：三模型状态通道的有限差分与VJP增益估计，中位相对差约2.2%；两档h的状态增益中位差不超过0.025%。Concat通道前者约0.8%–5.2%，D0两档h的增益约相差13.6%–13.7%，提示较大条件扰动已有非线性，不可把小梯度直接外推为全局线性响应。原数值见FINITE_DIFFERENCE_CROSSCHECK.json。

“合法换噪声增益”是同一C/Y/τ、两个真实q Gaussian的`RMS(Δr̂)/RMS(Δx)`。合法换realization保持Clean、使用同强度另一真实Y，并重建对应的q状态；它同时改变x和Y，是联合响应，不是纯Concat偏导。固定C/ε/τ改变Y时，总偏导含`JY+(a−d)Jx`。

独立地扰动Concat、固定状态改时间会偏离联合训练分布，只作局部敏感性/压力探针，**未把相应输出PSNR作为公平恢复消融**。τ是离散索引；时间VJP实际对连续原生输入`1000aτ`求导，不是假装对整数τ求导。

观察呈明显时刻差异：低噪声q含较多Clean信息，状态被较强利用；晚期状态含大量Gaussian，Condition更占主导。状态/时间作用不是0，但也没有依据声称二者与Condition同等重要。训练前后变化见三模型同协议表；因为D0同时经历湍流域适配和新增LC，不能把变化全部归因于LC。

## 9. E：Condition/SDT与官方Reverse近似的局限

DiffUIR原目标是雨/雪/雾/低光/模糊五任务的共享状态分布。V6当前是单任务湍流，SDT的跨任务收益未被验证；它保留为预训练路径与Spec的组成。共享状态x的边缘不意味着`[x,Y]`失去任务信息：Concat一直保留完整Y。

## 10. 研究判断与未解决问题

1. **结构层面**：是官方所选路径的Residual Conditional Diffusion；随机τ、随机q、SDT、残差目标、条件Concat、时间调制、三步Reverse均保留，新增LC另列。不能称其为未经近似、严格校准的DDPM/DDIM后验采样器。
2. **行为层面**：所测x/时间/初始噪声依赖均可见；不支持“完全退化成只看Condition的普通单次网络”。但Condition很强、作用随τ而变，不能据此排除“强条件迭代恢复”的功能解释，更不能宣布已证实生成分布能力。
3. **性能层面**：三步相对同checkpoint一步的PSNR改善有配对证据；LPIPS/更多NFE并非一致领先。没有独立训练的同计算量直接恢复器对照，故未识别“扩散框架相对普通网络”的净因果优势。
4. **方法层面**：继续保留当前冻结的Lres+LC实验有局部经验依据，且原生支路未在代码或梯度上被关闭；不足以证明其优于native-only、LC-only或其他固定比例。新增LC对分布学习是否有长期副作用，需要同起点/数据/预算/验证协议的正式消融，当前不启动。
5. **工程层面**：未发现本次覆盖的V6活跃扩散路径偏离官方/Spec的实质实现错误。官方终端方差差异、粗步省项、L1 surrogate与精确score/ELBO的差别已登记为理论/研究限制，不能当作V6工程“全PASS即可忽略”。

需要正式消融/进一步证据才能回答：LC的独立因果收益、状态分支相对强Condition回归的必要性、SDT在单任务湍流的净收益、严格匹配终端/保留噪声差分项是否改善，以及有意义的后验不确定性。当前结果既不授权改方法，也不要求把负/混合结果隐藏。

给导师的简短表述可以是：**“D0保留了DiffUIR的随机扩散状态训练和时间条件；我们额外监督真实三步采样的末端。专项诊断显示状态/时间/噪声未被彻底忽略，三步在配对测试中有PSNR收益。不过模型明显受退化图Condition主导，我们尚未证明后验生成能力，也没有把官方简化Reverse说成精确DDIM。LC是否最优需正式消融。”**
